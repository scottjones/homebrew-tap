# Homebrew tap for Omarchy on Mac

```
brew install scottjones/tap/omarchy
```

Or tap once, then use the short name:

```
brew tap scottjones/tap
brew install omarchy
```

`omarchy` installs the Omarchy Installer app, the first step to running Omarchy on an Apple Silicon Mac (macOS 15 or later). Uninstalling the cask removes the app and its helper; it does not remove an Omarchy install. Use Remove Omarchy in the app for that.

The cask is updated automatically when a new installer release is published.
